# jacobianharvesthub-advanced-database-portfolio
Advanced Database Systems portfolio for Jacobian HarvestHub Limited, that covers database design, SQL query optimisation, transactions and concurrency, NoSQL data modelling, and distributed/cloud databases.

# 1. Portfolio Overview

This repository contains the practical database portfolio developed for
MIT 8103 Advanced Database Systems.

The portfolio demonstrates the application of advanced database concepts
to a realistic agricultural e-commerce and distribution business scenario.

The project covers database design and modelling, query processing and
optimisation, transactions and concurrency, NoSQL and advanced data models,
and distributed/cloud database concepts.

The portfolio is based on a single case study:

  *Jacobian HarvestHub Limited*

Jacobian HarvestHub Limited is a simulated agricultural e-commerce and
distribution platform that connects farmers and agricultural suppliers
with customers through an online marketplace.

---

# 2. Case Study

 Organisation: Jacobian HarvestHub Limited

 Business Type: Agricultural E-Commerce and Distribution Platform

 Business Description

Jacobian HarvestHub Limited operates a digital marketplace through which
farmers and agricultural suppliers can list products for sale while
customers can browse products, place orders, make payments, and track
deliveries.

The system also supports inventory management, supplier management,
order fulfilment, delivery tracking, and customer reviews.

The database serves as the central data management system supporting these
business operations.

# 6. Portfolio Objectives

The objectives of this portfolio are to demonstrate the ability to:

1. Design and model a relational database for a realistic business scenario.
2. Develop and execute SQL queries.
3. Analyse and optimise database queries.
4. Demonstrate transaction processing and concurrency concepts.
5. Apply NoSQL and advanced data modelling approaches.
6. Explore distributed and cloud database concepts.
7. Evaluate database design and technology decisions.
8. Document and provide practical evidence of database implementation.
